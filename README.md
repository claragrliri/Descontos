
# ​​💰 ​Calculo de Descontos em Python 
Este é um programa simples em **Python** para calcular o desconto dado em determinado valor de compra.

# ​​📌​ ​Regras dos Descontos 
*O código aplica as seguintes faixas de desconto:*

**Compra abaixo de R$200:** 5% de desconto.

**Compras entre R$200 e R$299,99:** 10% de desconto.

**Compras a partir ou maior que R$300:** 15% de desconto.
